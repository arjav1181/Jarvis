# Code of Conduct

## The short version

Be decent. Assume the other person is trying.

## Expected

- Criticise the code, not the person. "This breaks when the file is missing" is
  useful; "you clearly did not read the function" is not.
- Say when you were wrong. Nobody here is pretending to be infallible; the
  project has a changelog full of bugs found by being honest about them.
- Respect people's time. A pull request that fixes one thing is worth more than
  a pull request that fixes eleven things and cannot be reviewed.

## Not acceptable

- Harassment of any kind, including sustained disruption.
- Publishing someone's private information, or a credential they pasted by
  accident. If you find a leaked secret, report it privately and do not
  announce it.
- Sexualised language or imagery.
- Deliberately breaking something to see what happens.

## Scope

This applies in the repository, in issues and pull requests, and anywhere
someone is representing the project.
